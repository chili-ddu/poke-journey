# 포켓몬 원본 격자 · 2배 프레임

493종의 일반색·이로치 986세트, 17,307개 물리 시트에 대한 표시 전용 자료다. 이미지·동영상 모델로 생성한 캐릭터가 아니다. 기존 PMD 픽셀을 원래 격자에서 이동하거나 원본 자세를 유지하는 오프라인 보간이며, 파이리는 승인한 별도 2배 프레임 샘플을 채택했다. 원본 PNG/XML과 기존 게임의 색 보정은 보존했다.

원래 키 사이에는 중간 그림 하나만 선택한다. 원본 키 시작 시각, 전체 길이, 공격 판정 프레임과 피해 공식은 원본 메타데이터를 계속 사용한다. 한 60Hz 틱은 비어 있지 않은 두 120Hz 슬롯으로 나눈다. 정지·종료 자세는 유지하며, 잘림·형태 손실·새로 생긴 프레임 QA 문제는 원본 자세로 대체한다. 따라서 모든 추가 칸이 새로운 그림은 아니다. 날개·긴 몸체와 이미 승인한 할퀴기·비행 순서는 보수적으로 처리한다.

`####.json`은 해당 종의 일반색·이로치 프로필이다. `manifest.json`은 작은 종 목록이며, 런타임은 사용 중인 종의 프로필만 읽는다. 원본 오프셋의 머리·몸통 기준점과 중간 그림의 이동량을 함께 제공한다. NPC·UI·이펙트는 기존 4단계 자료를 계속 사용한다.

재생성은 프로젝트의 sprite Python 환경에서 `python tools/bake_pokemon_motion_2x.py --jobs 4`를 실행한다. 이후 `tools/audit_pokemon_motion_2x.py`, `tools/refine_pokemon_motion_2x_guards.py`의 원본 비교·보수적 보정과 Godot 리소스 재가져오기, 런타임 검증을 수행한다. 베이크 캐시에 기록된 승인·검수 대체 프레임은 보존한다. 원본을 바꾼 경우 새 검수 라운드가 필요하다.
